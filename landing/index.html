Questions, answered

Frequently asked questions

Does ContextVault upload my source code?

ContextVault performs project scanning, chunking, embedding generation, and search locally with Ollama. It does not automatically send project source files to a hosted embedding API. When you use an AI desktop client, that client receives the tool results you request.

Which tools can connect to ContextVault?

ContextVault exposes an MCP server with project indexing and semantic search tools. It can be configured with compatible MCP clients, including Claude Desktop and Cursor.

What do I need before using it?

Install Ollama for Windows before running the installer. ContextVault prepares Node.js 22 and project dependencies; the first launch downloads the nomic-embed-text embedding model if it is not already available.

Can ContextVault keep its index up to date?

Yes. After you index a project, the live watcher monitors file additions and changes and updates the local index.
